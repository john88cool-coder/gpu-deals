1 · Быстрый старт

Установка

uv sync --extra dev
# для dns-playwright:
uv sync --extra dns && playwright install chromium
cp .env.example .env  # TELEGRAM_BOT_TOKEN + CHAT_ID

Запуск

gpu-deals crawl                # полный обход 9 магазинов
gpu-deals crawl --shop kaspi  # один магазин
gpu-deals digest              # недельный дайджест
gpu-deals render-dashboard --out site/index.html

Конфиг

# src/gpudeals/config.py
INTERESTED_CHIPS = {5070Ti,5070,5060Ti,9070XT,9070,9060XT}
WATCHED: 5070→365k · 5070Ti→525k · 9060XT→250k
card_budget 600k / build_budget 1M
owner: RTX 2070 SUPER (сравнение в алертах)

Совет: правьте цели в config.py — дашборд и алерты перестроятся автоматически.

Почему круто

  • Сравнение за 14 дней — DRAM дорожает.
  • Класс = чип+VRAM, иначе 8 vs 16 ГБ смешались.
  • Карты и сборки — разные медианы.
  • Дайджест/heartbeat читают базу без обхода.
